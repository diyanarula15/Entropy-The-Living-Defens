─────────────────────────────────────────────────────────────────────────────
QUICK START (3 STEPS)
─────────────────────────────────────────────────────────────────────────────

1. OPEN TERMINAL AND NAVIGATE:
   cd /Users/apple/Desktop/game

2. BUILD THE PROJECT:
   ./gradlew build

3. RUN THE GAME:
   ./gradlew run

That's it! The game window will open automatically.

─────────────────────────────────────────────────────────────────────────────
SYSTEM REQUIREMENTS
─────────────────────────────────────────────────────────────────────────────

✓ Java 21 or later (not just JDK 21 - must be 21+)
✓ macOS, Linux, or Windows
✓ 4GB RAM minimum
✓ OpenGL 2.1+ capable graphics card
✓ 500 MB disk space

The gradle wrapper (gradlew) is included - you don't need to install Gradle!

─────────────────────────────────────────────────────────────────────────────
WHAT HAPPENS WHEN YOU RUN
─────────────────────────────────────────────────────────────────────────────

1. First run: Gradle downloads ~500MB of dependencies (one time)
2. Compilation: Takes 30-60 seconds
3. Game window: Opens at 1280×960 resolution
4. Ready to play!

─────────────────────────────────────────────────────────────────────────────
KEY COMMANDS
─────────────────────────────────────────────────────────────────────────────

IN GAME:
  Left Click   → Paint green cells
  Right Click  → Erase cells
  P            → Pause/Unpause
  R            → Spawn test glider
  G            → Spawn glider gun
  B            → Spawn block
  S            → Save grid (savegame.json)
  L            → Load grid (savegame.json)
  C            → Clear grid
  ESC          → Exit game

DEVELOPER:
  ./gradlew test    → Run unit tests
  ./gradlew clean   → Remove build files
  ./gradlew build   → Rebuild project

─────────────────────────────────────────────────────────────────────────────
TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Problem: "Command not found: ./gradlew"
Solution: Make sure you're in /Users/apple/Desktop/game directory

Problem: "Java version error"
Solution: Install Java 21+ from https://www.oracle.com/java/technologies/

Problem: "First build takes forever"
Solution: Normal - downloading ~500MB of dependencies. Only happens once.

Problem: "Game is slow"
Solution: Normal on first run. Press P to pause if needed while exploring.

Problem: "Can't paint cells"
Solution: You might be overheated. Wait 2-3 seconds for heat to cool down.

KEY FEATURES
─────────────────────────────────────────────────────────────────────────────

🎮 GAMEPLAY:
  • Paint living cells that evolve by Game of Life rules
  • Defend against enemies moving toward your base
  • Heat system limits how fast you can build
  • 8 unique patterns to choose from

⚡ PERFORMANCE:
  • 60 FPS rendering + 10 TPS simulation
  • Handles 10,000+ enemies simultaneously
  • O(n) Game of Life with active cell tracking
  • Spatial hashing for collision detection

🏗️ ARCHITECTURE:
  • Entity Component System design
  • Double-buffered grid state
  • Flow field pathfinding
  • Separation of concerns across packages

─────────────────────────────────────────────────────────────────────────────
ADVANCED USERS
─────────────────────────────────────────────────────────────────────────────

MODIFY THE GAME:
  1. Edit src/main/java/com/lifedefense/[package]/
  2. Run ./gradlew build to compile
  3. Run ./gradlew run to test
  4. Run ./gradlew test to run unit tests

ADD NEW PATTERNS:
  1. Open: src/main/java/com/lifedefense/entities/PatternFactory.java
  2. Add a new static method
  3. Rebuild: ./gradlew build

TUNE DIFFICULTY:
  1. Open: src/main/java/com/lifedefense/config/GameConfig.java
  2. Modify constants like SPAWN_INTERVAL, CELL_DAMAGE, etc.
  3. Rebuild: ./gradlew build
